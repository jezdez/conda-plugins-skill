# Security

This repository distributes agent instructions, code examples, and installation guidance. Report unsafe commands, credential exposure, misleading security guidance, or unexpected behavior in validation and packaging.

Contact the repository maintainer, Jannis Leidel, through your established private collaboration channel. Include the affected file and revision, the circumstances required to reproduce the issue, and the impact you observed. Remove credentials and unrelated private information from examples. Do not post sensitive reports in public issues.

The maintainer evaluates reports against the current `main` branch. The project has no separate supported release branches. For concerns in an upstream plugin, also follow that project's security policy and contact its maintainers directly.
