# Security

This repository distributes agent instructions, code examples, and installation guidance. Report unsafe commands, credential exposure, misleading security guidance, or unexpected behavior in the validation and packaging scripts.

Contact the repository maintainer, Jannis Leidel, through your established private collaboration channel. Include the affected file and revision, the circumstances required to reproduce the issue, and the impact you observed. Remove credentials and unrelated private information from examples. Do not post sensitive reports in public issues.

Reports are evaluated against the current `main` branch. The project has no separate supported release branches. A concern in an upstream plugin should also follow that project's own security policy. Linking to a plugin here does not make this repository its security reporting contact.
