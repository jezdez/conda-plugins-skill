# Conda plugin skills

A private collection of Agent Skills for colleagues developing conda plugins with Codex, Kilo, or Claude Code.

Start with the [installation guide](skills/conda-plugins/README.md). The [conda-plugins skill](skills/conda-plugins/SKILL.md) uses repository instructions progressively and links to focused guides for conda APIs, testing, and examples from recent plugins.

## Get started

Colleagues need read access to this repository. Clone it with the GitHub CLI:

```sh
gh repo clone jezdez/conda-plugin-skills
cd conda-plugin-skills
```

Copy `skills/conda-plugins/` into the appropriate client directory using the installation guide. Keep the whole folder together.

Superpowers, Humanizer, and Ponytail are recommended companions. Their upstream links and installation guidance are in the [skill installation guide](skills/conda-plugins/README.md#recommended-companion-skills).
